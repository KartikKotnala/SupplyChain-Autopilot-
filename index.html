Problem Statement & Agent Mapping

In modern manufacturing, industrial assembly lines stop when a single critical component hits stockout. Here is how the problem is broken into 4 distinct failure points and solved by specialized agents:

Sub-Problem
The Real-World Pain Point
How It Is Solved in Code
Assigned Agent
1Stock Blindspots
Factories discover component shortages only after bins hit zero, halting workers.
Calculates dynamic buffer days ($Available / BurnRate$). Emits ShortageAlert when stock breaches safety thresholds.
ADK Inventory Agent
(via erp-db-mcp)
2Manual Sourcing
Procurement officers manually email vendors, getting incompatible MOQs, capacities, or expired terms.
Automates qualified vendor discovery, drafts standardized RFQs, and collects structured RFQAndQuotesList.
CrewAI Sourcing Agent
(via A2A Protocol)
3Downtime Blindness
Buyers pick the cheapest unit price, ignoring that delivery delays cause ₹15k/day in factory downtime.
Multi-criteria utility optimization: scores acquisition cost vs downtime penalties deterministically. Pauses for HITL.
ADK Risk Agent
(via calc-mcp)
4Invoice Fraud / Errors
Accounts payable pays invoices without verifying warehouse receipts, causing leakage.
Performs deterministic 3-way matching: PO Qty == Received Qty == Invoiced Qty and PO Price == Invoiced Price.
CrewAI Logistics Agent
(via calc-mcp)
Every agent earns its place: No random agents, no overlapping roles. Merging any two re-introduces that specific failure mode.

Wire Protocols & Boundaries

Real Wire Protocols — Real Boundaries

No hidden in-memory function calls. All agent communication, tools, and shared context enforce strict process and protocol boundaries.

Two FastMCP Servers

  • erp-db-mcp (:get_inventory, :get_qualified_suppliers) — parameterized read-only queries; no raw SQL
  • procurement-calc-mcp (:tradeoff_scoring, :three_way_match) — pure deterministic math
  • Zero LLM hallucination in pricing or reconciliation

A2A Protocol v1.0

  • CrewAI service serves the Agent Card at /.well-known/agent-card.json on port 8001
  • Google ADK acts as the A2A Client via POST /api/a2a/message/send
  • Interoperability verified: ADK discovers and offloads tasks to CrewAI seamlessly

PostgreSQL Blackboard

  • Append-only blackboard_entries table stores immutable JSONB artifacts with trace IDs
  • Separation of concerns: business workflow authority in procurement_workflows
  • Hover Blackboard: Interactive inspector in UI
Human-in-the-Loop Safe Sequencing: Consequential purchases pause at PENDING_HITL. Purchase Orders are issued ONLY after explicit human approval, leaving the interrupt state side-effect free.

Prompt Engineering & Variance Evaluation

Architectural Prompt Styles: ReAct vs. Few-Shot

Comparing Standard (Zero-Shot), Few-Shot (In-Context Exemplars), and ReAct (Thought/Action/Observation) across token economy, latency, and reasoning depth.

Token Consumption & Latency Trade-Off

Prompt Variance

Architectural Prompt Styles

1. Standard (Zero-Shot Contract) 1,662 tokens · 7.1 ms
Strict field constraints and Pydantic JSON schema definition. Lowest inference cost (₹0.041/run) and highest throughput.
2. Few-Shot Exemplars 2,400 tokens · 6.0 ms
Embeds 2 worked reference procurement decisions. Eliminates schema formatting errors and hallucinated supplier IDs without latency penalty.
3. ReAct (Reasoning Loop) 3,100 tokens · 15.0 ms
Iterative Thought → Action (call_mcp_tool) → Observation → Final Decision. Provides full multi-hop provenance for audits.
Prompt templates are fully decoupled in services/adk_orchestrator/prompts.py and independently verified by unit tests (test_prompt_rendering_variants).

Security & Callbacks

Security Guardrails & Auditability

Untrusted supplier quotations, user queries, and invoice remarks are scanned before entering agent context. Every agent and tool step triggers telemetry callbacks.

Input Guardrails & Injection Defense

  • Prompt Injection Scanning: Catches "ignore previous instructions", exploit payloads, and SQL attempts
  • Boundary Checks: Rejects negative quantities, absurd unit prices (>₹10M), or invalid lead times
  • Safe Redaction: Malicious payloads blocked and flagged as PROMPT_INJECTION_OR_EXPLOIT in real time

Callback Telemetry & Tracing

  • Lifecycle Hooks: ADKAgentCallback (before/after/error), MCPToolCallback, and CrewAI task callbacks
  • Audit Endpoint: GET /api/callbacks exposes live execution durations, inputs, and outputs
  • Observability: OpenTelemetry trace context (trace_id) propagated to Arize Phoenix
Live interactive test console built directly into Tab 2 of the React Dashboard for real-time prompt injection demonstrations.
