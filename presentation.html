Why Exactly 4 Agents

Every agent maps 1:1 to a distinct, measurable failure mode in industrial procurement. Merging any two re-introduces the pain point; adding a fifth would introduce unnecessary overhead.

Wire Protocols & Boundaries

Real Wire Protocols — Real Boundaries

No hidden in-memory function calls. All agent communication, tools, and shared context enforce strict process and protocol boundaries.

Two FastMCP Servers

  • erp-db-mcp (:get_inventory, :get_qualified_suppliers) — parameterized read-only queries; no raw SQL
  • procurement-calc-mcp (:tradeoff_scoring, :three_way_match) — pure deterministic math
  • Zero LLM hallucination in pricing or reconciliation

A2A Protocol v1.0

  • CrewAI service serves the Agent Card at /.well-known/agent-card.json on port 8001
  • Google ADK acts as the A2A Client via POST /api/a2a/message/send
  • Interoperability verified: ADK discovers and offloads tasks to CrewAI seamlessly

PostgreSQL Blackboard

  • Append-only blackboard_entries table stores immutable JSONB artifacts with trace IDs
  • Separation of concerns: business workflow authority in procurement_workflows
  • Hover Blackboard: Interactive inspector in UI
Human-in-the-Loop Safe Sequencing: Consequential purchases pause at PENDING_HITL. Purchase Orders are issued ONLY after explicit human approval, leaving the interrupt state side-effect free.

Architectural Prompt Styles

  • Standard Prompt: Explicit constraints, mathematical definitions, and Pydantic schema return. (1,600 tokens/run)
  • Few-Shot Prompt: Includes 2 worked reference procurement decisions from previous industrial cycles. (2,400 tokens/run)
  • ReAct Prompt: Reason $\rightarrow$ Action $\rightarrow$ Observation cycle with explicit tool-use stop conditions. (3,100 tokens/run)
Prompt templates are fully decoupled in services/adk_orchestrator/prompts.py and independently verified by unit tests.

Security & Callbacks

Security Guardrails & Auditability

Untrusted supplier quotations, user queries, and invoice remarks are scanned before entering agent context. Every agent and tool step triggers telemetry callbacks.

Input Guardrails & Injection Defense

  • Prompt Injection Scanning: Catches "ignore previous instructions", exploit payloads, and SQL attempts
  • Boundary Checks: Rejects negative quantities, absurd unit prices (>₹10M), or invalid lead times
  • Safe Redaction: Malicious payloads blocked and flagged as PROMPT_INJECTION_OR_EXPLOIT in real time

Callback Telemetry & Tracing

  • Lifecycle Hooks: ADKAgentCallback (before/after/error), MCPToolCallback, and CrewAI task callbacks
  • Audit Endpoint: GET /api/callbacks exposes live execution durations, inputs, and outputs
  • Observability: OpenTelemetry trace context (trace_id) propagated to Arize Phoenix
Live interactive test console built directly into Tab 2 of the React Dashboard for real-time prompt injection demonstrations.
